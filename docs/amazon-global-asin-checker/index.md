## 一、概述

“亚马逊全球 ASIN 状态检测器”（Amazon Global ASIN Checker，以下简称“本扩展”）是一款面向 Amazon 商品链接核查与运营观察的浏览器扩展。

本扩展根据用户主动发起的操作，检测指定 ASIN 在所选 Amazon 站点的页面状态，整理商品链接、评分、Ratings、Offer、购买能力、卖家、跳转以及价格优惠等信息。用户还可以在本机管理产品与关联 ASIN，手动更新评分历史，查看变化，并导出分析文件或备份。

本政策说明本扩展处理的信息、使用目的、权限、存储、导出、共享及删除方式。相关数据保存在用户当前浏览器本地，不上传至开发者服务器。

## 二、本扩展处理的信息

### 1. 用户输入与管理信息

本扩展处理用户主动输入、粘贴、导入或通过商品页入口读取的 ASIN、Amazon 商品链接和所选检测站点。

使用产品与 ASIN 监测功能时，还保存用户设置的产品身份、Model 名称、主售及关联链接角色、关联 ASIN、颜色、备注、关注站点、主售站、参考站、目标、基线和排序。这些是本机管理信息，不代表 Amazon 官方的产品或评价绑定关系。

### 2. Amazon 页面信息

为执行用户指定的任务，本扩展读取相关页面中的必要信息，包括：

- 页面标题、请求 ASIN、实际 ASIN、商品 URL 与跳转结果；
- 商品星级、Ratings 数量、五星至一星的占比及数据来源；
- Offer、购买表单、购买条件、卖家和缺货等页面状态；
- 高级模式中的报价、币种、参考价、活动、商品标识、优惠力度、资格条件及相关原文；
- 登录提示、验证码、访问异常及影响任务执行的页面提示。

星级占比仅从普通商品详情页读取；本扩展不会为了获取占比自动进入评论页或登录页。

### 3. 配送地区信息

配送初始化及核验可能处理邮编、城市、国家和页面显示的配送地区。本扩展可能向 Amazon 提交初始化所需的配送邮编，并核验页面是否接受该地区。这一操作可能影响当前浏览器 Amazon 会话的配送环境。

本扩展不通过设备定位接口获取 GPS 精确位置。

### 4. 检测结果、设置与诊断

本扩展保存检测结果、检测时间、配置、任务进度、必要的恢复状态、阶段耗时及相关错误或诊断信息，用于结果展示、问题排查和任务恢复。

本扩展不记录一般浏览历史、鼠标轨迹、滚动轨迹、按键内容或跨站点击活动。

## 四、本地存储与容量权限

### 1. `storage` 权限

该权限用于保存扩展设置、用户配置、产品关系、检测结果、任务进度及必要的恢复信息。任务与配置等数据使用浏览器本地的 `chrome.storage.local`、`chrome.storage.session` 保存；有效日历史使用 IndexedDB 保存。

本扩展不将这些数据保存至开发者的云端服务。

### 2. `unlimitedStorage` 权限

该权限用于支持最多 100 个关注 ASIN 的多站点本地历史及备份处理需求，减少浏览器默认存储配额对正常功能的限制。

该权限不会扩大网站访问范围，也不表示设备磁盘空间无限。实际可用容量仍受设备和浏览器环境限制。

## 五、下载权限

本扩展使用 `downloads` 权限，将用户主动发起导出的文件保存至本地设备，包括：

- 全球检测结果和关注历史的 Excel 分析文件；
- 产品与 ASIN 监测配置及历史的专用备份文件；
- 星级占比采集日志；
- 配送初始化诊断文件。

本扩展不会利用该权限扫描下载目录或读取其中的其他文件。下载文件独立于扩展内部存储，由用户自行管理。

## 六、标签组与右键菜单权限

### 1. `tabGroups` 权限

该权限用于组织检测任务创建的 Amazon 工作标签页，便于用户管理任务页面。标签组权限本身不会赋予对其他网站内容的访问权。

### 2. `contextMenus` 权限

该权限用于在扩展图标的右键菜单中提供打开独立工作区的入口。本扩展不通过该菜单采集用户选中的网页文本或浏览轨迹。

## 七、数据导出、备份与导入

### 1. 分析导出

Excel 文件用于查看和分析检测结果及历史，不作为无损恢复扩展数据的导入格式。

### 2. 专用备份

专用备份包含用户的监测配置、产品关系和历史数据；数据量较大时可能分卷。本扩展为备份提供完整性校验，但备份文件未加密，校验不等同于保密保护。

备份可能包含 Model、备注、链接关系及其他用户填写的管理信息。请妥善保管，并在分享前检查文件内容。

### 3. 合并导入

本扩展仅在用户主动选择文件后读取其内容，并在本机完成校验、暂存及合并。当前支持合并导入：已有 ASIN 的本机配置优先，不提供覆盖本机配置的完整恢复。

多卷备份按卷处理，不承诺整个多卷集合一次性完成原子恢复。备份导入不会将文件上传至开发者或第三方服务器，也不会授权本扩展读取设备上的其他文件。

## 八、个人信息与账户安全

本扩展的功能不要求用户向开发者提交身份信息或 Amazon 账号密码。

本扩展不会读取、保存或上传账号密码、Cookie 值、认证令牌、银行卡信息、支付凭据或用户交易记录。浏览器访问 Amazon 时仍会按浏览器及网站的正常机制使用现有会话，这不表示本扩展提取或保存相关凭据。

页面可见的价格和支付优惠门槛仅作为商品报价条件处理，不用于获取用户的财务资料或判断用户账户资格。

遇到需要登录、验证码或无法识别的阻挡页面时，由用户人工处理。本扩展不自动确认这些操作。

## 九、数据出售、广告与有限使用

本扩展不会出售用户数据，不使用广告或分析 SDK，不进行跨站跟踪，也不将数据用于广告画像、信用评估或贷款决策。

数据处理仅服务于本政策列明的商品链接核查、手动监测、本地管理、导出及备份用途。本扩展的数据使用遵守 Chrome Web Store 用户数据政策及有限使用要求，不请求 Google 账户 API 数据。

## 十、第三方服务与网络访问

本扩展直接访问用户选择的 Amazon 站点，以执行检测及配送核验。Amazon 会依据其自身政策处理正常的网站请求、会话及配送地区信息。

除上述 Amazon 网站访问外，本扩展不会主动将检测结果、配置、产品关系、历史或备份发送至开发者及其他第三方服务器。当前版本不使用开发者云端 API、远程存储、广告服务、分析服务或远程可执行代码。

如用户主动发送导出文件或诊断资料以寻求支持，接收方将获得用户选择分享的内容。该行为由用户决定，本扩展不会自动发送这些文件。

## 十一、数据保留与删除

### 1. 历史保留

每个关注 ASIN 在每个站点按本地自然日保留最近 360 天的每日最后有效记录；失败检测不覆盖已有有效记录。基线与管理配置按各自设置保留，不因每日历史保留窗口自动清除。

关注数据仅在用户主动更新后变化，本扩展不进行定时轮询。

### 2. 用户主动清除

用户可通过扩展提供的入口清除检测结果、移除关注 ASIN 或清除指定 ASIN × 站点的历史：

- 清除检测结果不会自动删除关注配置和监测历史；
- 清除当前站点历史保留该关注项的配置、目标及历史基线；
- 移除关注项时，历史是否删除按用户选择处理。

卸载扩展会移除该扩展的浏览器本地数据。卸载扩展不会自动撤销已由 Amazon 接受的会话配送地区。

### 3. 已下载文件

卸载扩展或清除扩展数据不会删除已下载的 Excel、备份或诊断文件，也不会删除用户另行保存的副本；这些文件需由用户自行删除和管理。
