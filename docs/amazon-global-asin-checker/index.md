# 亚马逊全球 ASIN 状态检测器隐私政策

英文名称：Amazon Global ASIN Checker。开发者：风子羽。

当前适用版本：V2.8.13。

## 处理哪些数据

处理用户主动输入或读取的ASIN、所选Amazon域名、商品与跳转URL、配送邮编/城市/国家、页面标题、星级、Ratings、五档占比、Offer、购买能力、卖家及异常提示。高级模式还读取报价、币种、参考价、活动、优惠条件、原文及来源；记录检测时间、阶段耗时和必要诊断。

本机管理信息包括产品身份、Model、链接角色、关联ASIN、颜色、备注、关注站点、目标、基线和排序。公开页面数据不能证明Amazon内部关系或账户优惠资格。

## 用途与访问方式

仅用于用户发起的跨站检测、配送初始化和核验、手动关注历史、结果展示、任务恢复、分析导出及备份合并导入。右键菜单只打开本扩展工作区，不采集所选文本或页面点击轨迹。

扩展直接访问用户选择的Amazon站点，使用浏览器现有Amazon会话与配送环境，但不读取、保存或上传Cookie值、密码或认证令牌。为判断报价读取可见价格和支付优惠门槛，不读取用户银行卡、交易记录或支付凭据。遇到登录、验证码及未知遮挡由用户人工处理。

## 本地保存、导出与导入

任务、配置、摘要和最近状态使用chrome.storage.local/session；有效日历史使用IndexedDB。同一ASIN×站点按本地自然日保留最近360天最后有效记录；失败不覆盖有效记录。unlimitedStorage支持本地历史容量，不保证磁盘无限。

只有用户主动操作才生成Excel、专用备份、占比采集日志或初始化诊断。专用备份包含管理配置和历史，未加密，可能分卷；导入在本机校验、暂存及合并，保留已有ASIN本机配置。跨卷不承诺一次原子恢复。下载文件独立于扩展存储，应由用户妥善保管。

## 共享与有限使用

除访问用户要求的Amazon页面外，数据不发送到开发者或其他第三方服务器。没有广告、分析SDK、远程可执行代码或跨站跟踪，不出售数据，不用于广告画像或信用评估。

数据使用遵守Chrome Web Store用户数据政策及有限使用要求，仅服务于上述单一用途。扩展不请求Google账户API数据。关注无定时轮询，仅由用户点击更新。

## 清除与保留

用户可清除检测结果、移除关注或清除当前ASIN×站点历史。清除当前站历史保留关注配置、目标和历史基线；移除时按选择保留或删除历史。卸载会移除扩展本地数据，已下载文件仍需用户自行删除。

## 权限与网站范围

| 权限 | 用途 |
|---|---|
| storage | 保存本机配置、检测结果、任务状态与恢复信息；日历史另存于IndexedDB |
| downloads | 用户发起后保存Excel、专用备份、占比采集日志与配送初始化诊断；不扫描下载目录其他文件 |
| tabGroups | 组织检测任务创建的Amazon工作标签组 |
| contextMenus | 在扩展图标右键菜单提供独立工作区入口，不收集所选文本 |
| unlimitedStorage | 支持最多100个关注ASIN的多站点本地历史；不扩大网站访问范围，不保证无限磁盘 |

访问范围为以下22个Amazon站点的HTTPS www主机：amazon.com、amazon.ca、amazon.com.mx、amazon.com.br、amazon.co.uk、amazon.de、amazon.fr、amazon.it、amazon.es、amazon.nl、amazon.se、amazon.pl、amazon.com.be、amazon.ie、amazon.com.tr、amazon.ae、amazon.sa、amazon.eg、amazon.co.jp、amazon.com.au、amazon.in、amazon.co.za。

内容脚本在匹配站点加载，相关页面读取服务于用户发起的任务；不采集一般浏览历史。21站可执行配送初始化，南非站免初始化但参与检测；初始化可能向Amazon提交配送邮编，并影响当前浏览器会话的配送地区。Amazon仍按其自身政策处理正常网站请求与用户会话。本扩展不自动登录、绕过验证码、领取优惠或购买商品。
